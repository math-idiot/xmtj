# 介面素材

遊戲 UI 的零件:品質框、稀有度標、限定標、戰力圖示、星星、底框那些。
**網頁用這些的好處是跟遊戲裡長得一模一樣**,玩家一眼就認得出來。

## 為什麼這一類不套「一個東西一個資料夾」

介面圖不是實體:沒有編號、沒有屬性、沒有獲取途徑,查不到設定表。
硬塞進實體結構只會生出一堆只有一張圖的空資料夾。所以這裡平放。

## 兩層

- `介面/<來源圖集>/` —— 整包照遊戲自己的圖集名放,不自己分類。
  主要在 `commonnew`(通用)、`commonquality`、`commonqualitynew`(品質相關)。
- `介面/常用/` —— **網頁真的會用到的那幾個**,用看得懂的名字另存一份,
  例如 `品質框_紅.png`、`限定.png`、`戰力.png`。這層是人工挑的,不多,
  每個在 `清單.csv` 裡記原始檔名與來源圖集,查得回去。

## 現況

資產位置已經定位到:`com_icon_pzk01`~`07`(品質框,7 個品質)、`com_icon_zhanli`(戰力)、
`xianding`(限定)、`com_bg_kamian_01`~`05`(卡面底,依品質)、`com_baoshi_0`~`7`(寶石)。

**但裝置快取切出來的那份不可靠** —— 我開過 `xianding.png` 和 `com_icon_zhanli.png`,
出來是細長漸層條不是圖示,代表舊的 atlas 切圖座標有問題。要等 mumu 用 UnityPy
(Sprite 的 m_Name + m_Rect)重切一份才會正確,那批跟框飾 271 是同一輪。

另外「UR」那兩個字本身可能不是圖、是文字加漸層填色(`xianding.png` 剛好就是一條漸層,
很像是拿來填字的),所以稀有度標能不能當圖抓還不確定,等重切之後才知道。
